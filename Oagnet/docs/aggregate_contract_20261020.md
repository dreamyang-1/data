# 聚合条件与名单依赖的 ASL 契约修复

2026-10-20，本轮原问题全链路审计中的 Oagnet 子项。

- PROVEN：数量聚合阈值被契约当成普通属性值查询。字段解析无法找到“销售总数量”属性，反复进行无意义的来源值查询后拒绝执行。现在只对当前召回目录中唯一匹配、公式完整为一个登记聚合、底层字段有授权依据的指标生成并核验 HAVING；复合或未知公式仍不猜测。阈值和运算符保留原义。
- PROVEN：前序数据已经给出限定的订单键，但普通名称匹配会排除 ID/key，导致确认后的名单仍无法执行。现在明确的限定字段只在当前授权目录已登记时直接按该字段处理；自然语言名称仍按原有规则解析。
- `IN`/`NOT IN` 比较使用相同的有类型成员集合，不依赖列表顺序。少项、多项、不同值或类型不能冒充相同名单。

本轮仅修改上述最小调用链。保留既有问题/目录生成 ASL 路径、向量字段与标准值验证、Scope 和错误处理。没有对校验增加一组更严的业务规则，也没有用原词绕过向量标准化。
