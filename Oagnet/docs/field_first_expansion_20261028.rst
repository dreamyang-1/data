筛选值先按当前字段匹配，再按需扩大范围
====================================

现行规则
--------

依据用户 2026-10-28 补充要求：“只有在当前字段匹配不到的时候才可以扩大范围”。
本条取代同日上一版“字段确定后始终禁止扩大”的行为，不新增开关或并行旧路径。

1. 先在已确定字段及其已发布字典关系内匹配。
2. 当前范围已有匹配时，继续使用当前范围，其他字段的同名值不参与竞争。
3. 当前范围完全没有匹配时，才扩大到原请求授权、按实体归属筛选后的候选池。
   扩大后仍需有唯一的标准字段和值证据，不跨模型、业务域或无关实体借值。
4. 当前范围有多个候选属于歧义，不属于没找到；多值条件部分已匹配也不把
   整个条件换到另一字段。数值阈值、日期和明确编码保留既有字段及字面量合同。

例如，同一个“上海市”同时出现在省份和城市字典中，医院省份字段已有匹配时，
只使用省份字典。如果当前字段没有该业务值，才检查原授权候选池的其他字段；
若扩大后仍存在多个候选，保持歧义，不能取第一个或最高相似度结果冒充唯一值。
