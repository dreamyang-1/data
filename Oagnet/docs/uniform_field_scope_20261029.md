# 字段绑定范围统一修复

## 已确认原因

日期绑定独立于参数归属筛选。显式日期名称会直接在整个授权目录匹配，未利用已选维度的属性、指标时间口径及查询实体区分同名字段。指标候选也曾直接返回整个指标目录；筛选失败后的两处恢复路径会重新使用完整目录，已绑定字段的空值域还允许切换到其他属性。

模型 133 原问题为“以发货日期为维度，查询开票金额去年同期同比变动”。历史请求已选发货明细及时间维度；发货明细和开票发货核销明细均存在发货日期，旧路径误报时间歧义，导致后续计算任务跳过。

## 修改边界

- 继续使用当前请求的授权目录；不修改模型、业务域、向量索引或业务数据。
- `parameter_catalog` 对指标、维度、展示、筛选、排序及日期应用归属检查；指标采用登记来源依赖，维度采用登记实体及物理字段映射。查询主实体不代替每个字段的业务归属。
- 日期复用字段和维度匹配入口，使用已绑定维度属性、兼容的指标时间口径及主体归属区分同名日期。显式跨实体日期仍可使用。无法唯一确定时保留歧义，不接受模型任意选择日期。
- 删除未知归属后的全目录恢复和失败后的全目录扩张；绑定后的条件值仅在该字段及已发布字典边内匹配，禁止借其他属性的值改变查询条件。日期、数值阈值及明确编码保持既有字面量规则。
- 原有实体授权、跨实体关联解析、ASL 标准化和节点顺序不变。没有修改前端或 Java。
