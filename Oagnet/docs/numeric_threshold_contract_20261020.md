# 数值阈值在调用契约中的类型交接

PROVEN：当前目录 sales_order.quantity 的 data_type 缺失。ASL 已使用合法 JSON 数值0时，调用契约仍可能携带字符串"0"；既有标准值检查先通过 ASL 的数值阈值，再把调用方字符串当成业务名称检索，导致 ASL_FILTER_VALUE_UNGROUNDED。

仅为同一已绑定字段、相同大小比较运算符、完全相等的有限数值复用 ASL 已有类型，形成临时的调用方验证输入。不改原始契约、ASL或字面量；不同值、字段、运算符、布尔值及未定类型的字符串 ASL 均不能获得这个证明。名称及枚举仍必须匹配本字段的向量标准值。

服务器已有冻结的向量值校验函数及 vector_filter_grounding.py 在本地 Git 中尚不完整。本提交按服务器当前字节保留并补齐这一必要依赖；运行时只新增数值证明函数及两行调用，没有改动该冻结模块。与服务器快照逐字核对后，仅发布 agent.py 和 surface_literals.py 的必要差异。
