# ASL 恢复与基础任务关联修复

Current Stage：V1 基础查询、任务依赖与输出修复。同比/环比按用户要求暂不处理；未改变 V2 路由或开展替代切流。

## 已证实的根因与修改

- **PROVEN / Agent 说明读取**：活动模型的登记下载地址为空，但现有 model_sync 已生成真实说明文件。读取器只认登记地址，漏读了该文件。现在优先读取登记地址；地址为空时按既有生产者协议读取同模型的远程文件。真实文件、读取内容、规划模型完整上下文及洞察引用的 SHA-256 一致，正文 9435 字符；没有注入静态文本或合成目录兜底。
- **PROVEN / Oagnet 入口**：原有完整问题生成器仍在，主入口却只消费有限的规划提取参数。恢复现有 PromptBuilder 与原提示规则优先生成，提取参数作为参考，原有限绑定作为兼容路径。仍校验当前授权目录、已确认条件及不可执行的真实歧义。已选登记标量指标的数值阈值可还原为其完整目录公式。
- **PROVEN / SQL**：MySQL HAVING 重复引用标量指标公式中的未投影源字段，报 1054。仅对已选登记标量指标的精确数值比较复用输出别名；聚合指标、其他谓词、其他方言和无 HAVING 的查询保持现有行为。合作时长名单已实际完成 ASL、SQL 与结果返回。
- **PROVEN / 基础关联传参**：规划中的结果指代被错误当成经销商名称，同时进入筛选与实体提及。已用完整且同 Scope 的前序编码集合完成绑定，并同步清除该占位的重复实体解析。合同完整性用同一归一过程证明编码集合和剩余字面筛选仍完整保留，不改写原始 CurrentTurnFacts。用户真实字面值、排除条件、其他对象条件以及缺少已绑定依赖时的行为受负例保护。
- **PROVEN / 共享时间**：依赖任务已有 2025 年提取范围，却保留旧 ALL_TIME 标记，向 ASL 发出相互矛盾的要求。只在既有 DAG_BOUND_STRUCTURED_QUERY 路径成功解析该任务的声明范围时清除旧全历史标记；未声明范围的任务保持现有行为。
- **PROVEN / 输出**：月度查询已经成功，洞察层却读取不存在的 delta，导致独立子任务失败。改用计算结果实际提供的 absolute_change；上涨与下降复现均先失败后通过。
