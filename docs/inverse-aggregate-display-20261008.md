## 最小修复及边界

- SQL Translator：聚合展示路径允许沿当前请求的权威关系图正向或反向遍历，按实际方向换算基数；只使用 N:1/1:1 路径，连接片段仍通过既有连接校验。兼容标准基数枚举中的下划线。
- 查询主体推导默认行为不变。ASL 指标、维度、排序、限制、时间、过滤条件不变；不改授权范围，不自动添加语义关系。
- 展示关联失败分类为 `AGGREGATE_DISPLAY_RELATION_UNSAFE`，保留可安全提取的字段标识，任意异常尾文仍不公开。接口地址、请求结构、响应字段和节点顺序不变。
- DataAnalysis：明确指出失败发生在关联展示校验；未知失败不擅自认定查询主体缺失。无完成的选中结果时不导出，不追加存储提示；失败任务的旧数据集不参与导出。已完成结果和上游附件链接保留。
- Oagnet 无代码改动。无语义数据库写入、向量重建或 V2 切流。
