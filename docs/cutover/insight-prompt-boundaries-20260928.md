三类指导为：

- 没有统计诉求的明细名单、科室、联系方式以信息整理为主；数字编码不计算。明确要求分析明细金额、数量时仍可展开，不按固定关键词机械归类。

不修改模型、请求响应结构、ASL/SQL、图表接口、图表展示位置、节点顺序或宽松报告解析；没有新增内容校验、二次模型审核、数字白名单或强制三段式。现有长篇分析要求保留，少量数据不凑字数。
