# Source review and limits

First divergence (PROVEN): SQL_TRANSLATOR_CATALOG_READ. The existing translator
uses Redis payloads and separately refreshed MySQL definitions, with no common
publication identity. The private snapshot now supplies those SQL facts, and the
new consumer has no route back to either independent cache. Pin acceptance uses
the existing fresh authority and complete native inventory checks.

Current request scope is revalidated and compared exactly with both snapshot and
pin. SQL cannot introduce its own authorization grant. Database selection must
match the planned source; knowledge names remain in the request fingerprint.
An ASL alias cannot replace the canonical pinned metric code. Source resolution
walks governed dependencies and rejects missing/cyclic or multiple sources.

Relations lower only from declared fully qualified endpoint pairs. Unresolved
relationships are excluded from executable paths; required-table checks reject
omitted joins before pin acceptance. Registered sub-tables remain bound through
entity -> domain -> model and the same active data source. No public endpoint is
made model-wide to compensate for missing physical metadata.

The actual catalog uses numeric metric levels. Dependency expansion follows its
explicit dependency list; no numeric business classification is invented.
Existing SQL formula/alias helpers are reused; no new regex or prompt rule added.
The internal entry requires version 2.0/query. This is not a complete independent
ASL schema validator or a V2 TypedPlan compiler. Complex Boolean trees, repeated
entity aliases, nested composite semantics and comparison/result contracts still
need full lowering and result evidence before cutover. No query is executed.

Self-review only. Offline storage fixtures prove control flow and refusal, not
native persistence, live source results or production deployment. Actual metadata
replay hashes do not replace owner-approved business Gold labels. The 6 unresolved
relationships require catalog evidence before those joins can be accepted.
