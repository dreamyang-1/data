## 行为边界

- 仅 DETAIL_QUERY、ASL 无指标、返回列全部为名称/编号类列且至少包含名称列时适用。其他明细列、金额、日期、聚合与异常分析不变。
- 名称首尾空白去除后，按全部返回列稳定去重；不同编号、不同科室等任一列有差异均保留，不做相似名称合并。
- 所有名称列均为空或 `-`、`--`、`—`、`–`、`null`、`none`、`n/a` 占位时删除该行。部分名称缺失但其他名称有效时保留；未知/其他等业务标签不删除。
- 零、负数、较大金额不作为异常自动删除；未返回的隐藏实体编号无法用于区分同名实体，说明中明确不据此推断实体数量。
- 在洞察、最终表格和后续数据集保存之前统一清理；执行证据保留原快照、原行数与清理计数，数据集使用派生快照。源数据不修改。
- 完整数据清理后不继续附上未清理的上游文件，后续复用保存清理后的数据。预览仅清理本次可见数据，保留截断状态，全量去重后总数未知；附件如存在则明确标注为未清理原始完整结果，不将它导入为清理后数据集。
