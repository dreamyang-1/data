# 洞察阶段调用计算器

用户明确要求允许模型调用计算器，并删除“只引用确定性计算事实、不自行新增计算”的限制。本次只修改洞察生成及其内部模型调用；不改任务规划、ASL、SQL、向量标准化、前端或 Java。

## 实现

- 删除旧计算限制，以及专家提示词中与新能力冲突的“不调用工具”。允许模型基于本轮数据提出新的统计和四则运算。
- 注册 `insight_calculator` function tool。统计按数据源、字段及分组引用完整原始行；支持合计、记录计数、去重计数、平均、极值、中位数。结果包含分组记录数，数值解析及统计复用既有 numeric_operations 能力，普通加总使用 Decimal。
- 四则运算可引用此前工具结果的行和字段，或明确常量；不要求模型手抄明细金额。工具无 SQL、网络、文件或 Python 表达式执行能力，不能扩大数据范围。数据源仅来自本次调用已返回的数据，失败任务不注册为来源。
- 保留样本/截断信息；未知字段、越界索引、非有限数字和除零返回计算失败，不转换为零。限制调用轮次及分组输出规模；超限明确说明，不截取分组冒充完整汇总。
- 工具结果进入后续模型上下文及报告证据复核。工具调用后仍需输出 claims 与 final_answer；若模型只输出正文，会利用已有结果补齐格式，预算耗尽则明确失败。
- 保留前一轮选择的三个跨场景示例：英国 ONS 工资、美国 BLS 失业统计、澳大利亚发电统计。它们仅说明推断及结果选择边界，不作为本轮数据。

## 复现与验证方法

原问题：统计美敦力、波士顿科学两个品牌在二级医院的销售额，按品牌分组展示厂家名称。使用原请求的模型 130、业务域 296。

恢复前次原始模型输入中的完整数据、语义参考及上下文；日志末尾被截断的 report_contract 通过现有程序重新生成，不伪造缺失业务数据。隔离候选真实模型调用已经实际执行分组汇总、引用结果求倍数及占比，分组合计和记录数与原始数据独立计算一致，最终摘要完整。该重放是诊断补充，部署后仍从正常请求入口执行原问题及历史回归。

测试覆盖原来易算错的 12 行分组、零值记录、连续引用计算、不同请求隔离、部分数据范围、失败任务排除、字段错误可修正、除零失败，以及工具调用后漏掉最终摘要的恢复。原先禁止 tools 的测试断言按用户新要求更新；不修改无关既有失败。

最终测试、发布及业务回归结果见同目录验证记录。历史缺少原始范围或多轮上下文的条目仍标为未验证，不能用旧脚本默认模型代替。

## 文字输出兼容修复

真实模型有时先返回说明文字，再返回 Markdown 围栏中的 JSON。此前报告解析会将其当成整段正文，丢失 final_answer；证据复核解析也会失败，随后移除已有业务摘要。两处现在共用同一 JSON 提取方法，并分别验证报告或 reviews 的对象结构；保留原有纯 JSON、单独围栏及普通正文兼容行为。该修复只解决已复现的格式丢失，不将解析成功当作内容正确。

最终代码相关切片 127 项通过，隔离提交目录新增计算器测试 15 项通过。较早扩大切片 153 项通过、5 项既有语义文档测试失败（仍引用已不存在的 `_LOCAL_DESCRIPTION_PATH`）。共同全量基线 6127 通过、635 失败、8 错误；候选 6126 通过、636 失败、8 错误，唯一新增失败为旧的“禁止 tools”断言，已按本次明确要求修正并通过专项测试。该全量对照早于最终格式修复，最终格式修复采用相关切片验证，未宣称全量全绿。

对明确试图返回 final_answer、但错误地写成 Markdown 标题的响应，也使用同一格式修正轮次；未调用工具时依然生效。原有合法普通正文及 claims-only 解析保持兼容，避免为修复格式而破坏已验证的旧调用。
