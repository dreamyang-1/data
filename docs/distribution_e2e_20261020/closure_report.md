# 整单均价分布：任务规划与实际执行闭环

日期：2026-10-20。基线：`649dc53996d668b549b7b1bb3130d9a9adaba27c`。本轮只修复原问题及其改写暴露的调用链，不切换 V2，不修改业务目录、索引、权限或配置。

## 已确认业务口径

先找出指定医院在有效时间范围内、包含指定商品的完整订单名单；再按这些订单汇总整张订单全部商品的含税金额和销售数量；按登记口径保留净数量大于零的订单，逐单相除，最后分析逐订单均价的分布。没有指定时间时沿用当前模型登记的默认时间。入选条件与整单统计范围必须分开。

## PROVEN：实际复现及修复

1. **任务展开被误拒绝后退回单任务。** 登记口径中的数量大于零被当成用户未提供的新数字；另外，插入前置任务后旧文本中的“任务0”失效。现按选定指标的完整字段、运算符、数值提供 grounding 依据，只归一已声明前驱的文本引用，不把任意数字放行。
2. **名单被当作计算输入。** 模型可能只规划订单号查询，然后声称“不再查询数据库”，或附带不可执行的结果操作。现先检查登记公式输入是否可用；只有键名单时补齐取数任务，不能靠文字或无效操作制造金额、数量。已有真实明细字段的合法本地操作仍保留。
3. **成分查询继承了不该保留的筛选。** 复合指标展开原先复制商品筛选，算成指定商品的局部均价。现依据当前登记的“整对象全部明细”口径分开规划入选名单和整对象查询；后者只消费完整对象键，保留分组后的样本条件。同一整对象、粒度及有效样本范围的成分合并取数，其他口径继续分别取数。
4. **逐行字段改变了统计粒度。** 计算成分被当作展示字段加入分组，或参数提取另造原始行计算。现保留对象键和真实展示属性，登记输入仍走指标聚合；已绑定的登记公式不与未规划的原始行管道并行执行。
5. **时间及依赖对象丢失。** 新名单任务曾丢掉目录默认时间；调度器又从“全部商品”误选商品键。现名单保留授权的默认时间，依赖先锚定完整名单指向的对象。读取完整持久化数据及 SQL 字段来源，拒绝截断/采样数据，不把前十行当全量。
6. **内部提示污染业务语义。** 给本地计算添加数据库关联提示，把英文 display-name 当成待绑定业务名称。现计算任务不产生数据库关联要求；订单依赖明确要求目录中的订单号，不增加无关分组。
7. **ASL 正确，调用方仍误拦。** 分组已输出订单键，却因展示字段和分组重复、或静态中英文对照表不认识登记字段而判为丢失。现认可分组键本身也是输出列，且与已有明细逻辑一致，信任当前授权 ASL 服务确认的语义分组契约；空分组、V2 精确身份及显式严格粒度校验保留。
8. **ASL 契约把聚合阈值当普通属性值。** Oagnet 对唯一登记、公式完整可核验的聚合阈值使用 HAVING；已授权的明确限定键不再被名称字段启发式排除；IN 按相同的有类型成员集合比较。未绕过向量字段和值的标准化。详见 Oagnet 子项文档。
9. **SQL 聚合条件生成错误。** 语义指标名残留在 WHERE，造成未知列；仅替换 SUM 仍会错放聚合阶段。SQL Translator 按当前模型展开已选指标及依赖，区分 WHERE/HAVING，保留退货净额和原有连接。详见 SQL 子项文档。
10. **计算与分析事实失真。** 物理 order_key 未被识别为对象身份，分开的输入可能错位；模型也曾把预览猜成均值、中位数。现按已执行 SQL 的键对齐，完整数值样本由程序计算均值、中位数、分位数、总体标准差和等宽区间频数，再交给模型解释。普通计算不增加分布步骤。

## 最终链路与验证

问题级总意图保持已有行为。内部顺序为：任务边界、依赖及交付物规划 → 登记口径补齐输入 → 一次批量参数提取（顺带子任务意图）→ 原有指标归一 → ASL → SQL 与依赖调度 → 完整输入计算 → 程序统计事实与分析 → 最终输出。

用户可见七阶段仍为：意图识别 → 任务拆分与规划 → 解析校验 → 调度执行 → 结果校验 → 数据洞察分析 → 最终输出。原句和明确整单口径的改写均实际执行，逐项核对名单、参数、ASL、SQL、任务状态与结果事实；不是只看模型拆出几个任务。

独立只读查询核对入选集合完整性、整单金额/数量，以及计算结果；整单取数 SQL 不携带商品筛选或第二次时间截断。真实样本恰好没有混合商品，因此另加合成反例：指定商品价格为 100，而包含另一个商品后的整单均价为 250，零净数量整单应排除。该反例由实际编译 SQL 执行验证。

专项回归包括原句形态、缺输入/无效操作、同粒度联合输入、独立问题、跨问题依赖、反序键对齐、采样拒绝、分组确认和确定性统计。最终离线计数及 baseline/final、旧通过退化、旧失败修复和新增用例见 `test_delta.json`。历史失败不掩盖，不宣称全仓全绿。
