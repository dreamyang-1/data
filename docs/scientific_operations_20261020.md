# 常用数值与统计运算（2026-10-20）

## 范围与行为

扩展 Agent 本地确定性计算；先规划取数与计算任务，计算消费依赖任务的完整数据集，结果保存后可继续参与后续计算。业务字段和值仍由当前授权目录绑定，ASL/SQL 的生成、校验及服务未修改。

| 类别 | 已支持能力 |
| --- | --- |
| 基础数值 | 加减乘除、乘方、平方、立方、平方根、立方根、任意实数根、绝对值、取负、倒数、符号、整除、取余、两值最小/最大 |
| 科学计算 | 指数、自然/常用/二进制/指定底对数、expm1/log1p、三角及反三角函数、双曲及反双曲函数、弧度/角度转换、hypot、atan2 |
| 整数与舍入 | 四舍五入、向上/向下取整、截断、阶乘、最大公约数、最小公倍数、排列、组合、位与/或/异或/取反、移位 |
| 汇总统计 | 原有计数/求和/均值/最小/最大、去重计数、中位数、分位数、百分位数、总体/样本方差、总体/样本标准差、极差、乘积、平方和、均方根、几何/调和均值、总体/样本协方差、相关系数 |

共57种单值/双值运算与24种聚合函数名（含原有函数及总体/样本别名）。这不表示任意数学问题均可直接执行；复数、符号代数和矩阵未纳入本轮。多步计算沿用有界流水线或任务依赖，不执行任意代码。纯数字入口仅直接识别无歧义的单次运算，例如“计算2的10次方”“9的平方根”“round(2.675,2)”；复杂表达式继续进入规划。

- 四舍五入采用 HALF_UP，支持小数位及负位数；三角函数使用弧度，可显式转换。
- 方差/标准差默认总体口径除以 n，样本口径除以 n-1；显式名称与 ddof 冲突时报告错误。分位数采用 `(n-1)*q` 线性插值。
- 汇总统计跳过空值，成对统计仅使用双方均非空的样本；空样本、单样本样本方差、常量相关系数等不能伪装成0。
- 零除、实数定义域错误、非有限输入及溢出返回明确失败原因。旧 numerator/denominator 的正分母合同、编码对齐和完整性保护保留。
- 位运算限制为安全整数范围，阶乘、指数和移位有边界；不保证任意大整数的无损计算。

## 已证实的链路问题及修复

PROVEN：隔离真实接口中，“查询后计算方差”及“查询后计算平方/开根”曾仅返回查询数据。服务器新增的分析降级逻辑会把多个任务压成首个取数任务，遗漏显式计算目标。现在保留合法计算、多次取数及明确数学交付目标；不完整数学计划走纠错，不静默删除。原分析工具降级能力保留。

PROVEN：真实模型在规划阶段输出 `pipeline.steps`，执行合同使用 `operations`，提取阶段的正确结构又被规划边界覆盖。现在统一两种列表键，二者内容冲突时拒绝，不再丢失后续运算。

PROVEN：纯数字问题曾进入闲聊路径，单任务又可能被自动改为查库。现在仅对无业务条件、全为数值字面量的明确运算执行本地计算，保留 Pending 恢复和授权隔离。结果展示冻结7节点顺序。共享数值模块置于 `app/numeric_operations.py`，避免通过 services 包导入触发编排器循环导入；原 MinIO 独立四则与基础汇总仍无需导入 Agent 包。

- 新增159项测试覆盖全部运算类别、负数/零/溢出、舍入、统计定义、稳定方差、成对空值、公式绑定、非法表达式、流水线别名、依赖结果保存与复用、纯数字完整入口及7节点顺序。
- Critical 542/542通过。全量基线5338通过、232失败；最终5497通过、相同232失败。旧通过转失败0，收集错误0，新增159项全部通过。未修改历史失败断言。
- 隔离原生接口：统计问题拆为取数+计算，完整89组源样本，总体方差、样本方差、总体标准差与独立只读SQL取数及 Python statistics 计算一致。
- 平方/平方根问题拆为取数+计算，输出89组，结果预览20行按编码与独立源数据逐行一致；未将预览冒充完整样本。
- “计算2的10次方”返回1024，不调用数据库；原平均订单金额Top5及月度趋势链路完成，平均金额和身份排序与独立只读SQL一致。这些请求均完整展示冻结7节点。
- 审查结论：当前目标无剩余P0。改动限于数值计算、规划绑定与必要编排入口；保留服务器新增的指标目标合同、澄清问题链、趋势显示窗口和分析数值展示。5个相关服务器文件按原字节入库，不重复发布；无关 V2、推荐代码和配置不纳入本轮写入。

测试证据只记录状态、计数、列及核对布尔值，不提交业务行、凭据或运行日志。发布使用逐文件哈希、备份与并发差异保护，正式验收另补记录。Current Stage 为 V1 数值计算扩展；Catalog/Evaluation/Shadow 与 V2 替代状态不变，未进行语义库写入、索引重建或切流。
